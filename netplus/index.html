Final Review: Ports and Network Standards

Review what each service or standard does before the final assessment.

Common ports

Port numbers identify application services above IP. TCP emphasizes reliable delivery; UDP is often used for low-overhead requests or real-time traffic. A reachable host can still have a blocked service port.

ServiceTransportPortWhat it does
Exam clues: hostname failure → DNS 53; no DHCP lease → UDP 67/68 and relay; file share failure → SMB 445; secure directory connection → LDAPS 636; time drift → NTP 123; enterprise Wi-Fi authentication → RADIUS 1812.

Standards and related technologies

Numbers such as 802.1Q name IEEE standards. They are not port numbers. Use this list to connect the label to the feature you would configure or troubleshoot.

StandardPurposeWhen it matters
Do not confuse 802.1Q (VLAN tags on a trunk), 802.1X (access authentication), and 802.1AX/LACP (bundled links). STP/RSTP handles Layer 2 loops; LLDP identifies directly connected neighbors.
